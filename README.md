# FIND_YOUR_MIND

> **숙명여자대학교 2024 졸업프로젝트**  
> 얼굴 감정 인식을 기반으로 사용자의 감정에 반응하는 **공감형 3D 아바타 서비스**를 구현했습니다.

---

## 📌 Project Overview

**FIND_YOUR_MIND**는 카메라로 사용자의 얼굴 감정을 인식하고,  
인식 결과에 따라 3D 아바타가 공감 표현을 제공하는 모바일 서비스입니다.

단순히 감정을 분류하는 데서 끝나지 않고, 사용자의 최근 감정을 기록하고  
관련 음악·영상 추천과 심리상담 연락 기능까지 연결해 감정 인식 결과가 실제 사용자 서비스로 이어지도록 구성했습니다.

---

## 🎯 Goal

- 카메라 기반 실시간 얼굴 감정 인식
- 감정 결과에 따른 공감형 3D 아바타 표현
- 감정 변화가 지나치게 빠르게 반영되지 않도록 자연스러운 공감 과정 모델링
- 최근 감정 기록 및 사용자 상태 확인
- 감정과 연관된 음악·영상 콘텐츠 추천
- 부정적 감정 상태에서 심리상담 연락 기능 제공

---

## ⚙️ Main Features

### 1. 실시간 얼굴 감정 인식

Android 카메라로부터 사용자의 얼굴 이미지를 입력받아 Python 기반 감정 인식 모듈에서 분석합니다.

- 얼굴 영역 탐지
- 얼굴 이미지 전처리
- 얼굴 감정 분류
- 감정 결과 후처리 및 안정화

감정은 다음 7개 클래스로 분류합니다.

```text
NEUTRAL
HAPPY
ANGRY
DISGUST
SAD
FEAR
SURPRISED
```

얼굴 검출에는 **MTCNN**, 감정 분류에는 **MobileNet 기반 FER 모델**을 활용했습니다.

---

### 2. 감정 인식 결과 안정화

프레임마다 감정 결과가 빠르게 변하면 아바타의 표정도 계속 바뀌어 사용자 경험이 불안정해질 수 있습니다.

이를 줄이기 위해 연속된 감정 결과를 고려하는 **smoothing algorithm**을 적용해 감정 출력의 변동성을 줄였습니다.

---

### 3. 공감 과정 모델링

인식된 감정을 아바타가 즉시 그대로 따라 하는 대신,  
사람의 공감 과정처럼 일정한 시간 간격과 강도를 두고 반응하도록 설계했습니다.

- **1차 공감**: 사용자의 감정과 유사한 감정을 일정 시간 지연 후 표현
- **2차 공감**: 감정의 지속 시간과 강도를 고려해 더 깊은 수준의 공감 표현

이를 통해 단순한 기계적 표정 복제가 아니라 보다 자연스러운 감정 반응을 구현하고자 했습니다.

---

### 4. 2개의 3D 아바타 · 14가지 표정

사용자는 두 종류의 3D 캐릭터 중 하나를 선택할 수 있습니다.

각 캐릭터는 7개의 감정을 **2단계 강도**로 표현합니다.

```text
7 Emotions × 2 Levels = 14 Expressions
```

Unity의 **Blend Shape** 기능을 활용해 얼굴 표정을 구현하고,  
눈·입·볼 등 얼굴 근육 변화가 자연스럽게 보이도록 조정했습니다.

---

### 5. 최근 감정 기록

감정 인식 결과를 Firebase에 저장하고,  
사용자가 앱을 다시 실행했을 때 가장 최근에 저장된 감정을 메인 화면에 표시합니다.

```text
Emotion Recognition
        ↓
Firebase
        ↓
Latest Emotion
        ↓
Main Screen
```

---

### 6. 감정 기반 음악 · 영상 추천

가장 최근에 인식된 감정과 유사한 콘텐츠를 제공해  
사용자가 자신의 감정 상태에 맞는 음악과 영상을 빠르게 확인할 수 있도록 했습니다.

- 감정별 음악 플레이리스트
- YouTube 영상 연결
- 앱에서 관련 콘텐츠로 빠르게 이동

---

### 7. 심리상담 연락 기능

최근 감정이 부정적인 상태로 판단될 경우  
미리 등록된 심리상담소 정보를 팝업으로 제공하고 전화 앱으로 연결합니다.

프로젝트에서는 다음과 같은 부정적 감정을 기준으로 상담 기능을 연계했습니다.

```text
SCARED
ANGRY
SAD
```

이를 통해 감정 인식 결과가 단순한 시각적 피드백을 넘어 실제 도움을 받을 수 있는 서비스 기능으로 연결되도록 구성했습니다.

## 🏗 System Architecture

```text
Android
   │
   │ Camera Image
   ▼
Python Emotion Recognition
   │
   ├── Face Detection
   ├── Pre-processing
   └── Emotion Classification
   │
   ▼
Firebase
   │
   ├── Latest Emotion
   └── Emotion Data
   │
   ▼
Unity 3D Avatar
   │
   └── Empathic Expression
```

서비스는 **Android · Python · Firebase · Unity**를 연결하는 구조로 구현했습니다.

Android에서 전달된 이미지를 Python 서버에서 처리하고,  
추론 결과를 Firebase에 저장한 뒤 Unity가 감정 데이터를 받아 해당 표정을 출력하도록 구성했습니다.

---

## 🔄 Real-Time Process

```text
1. Android 카메라 이미지 획득
        ↓
2. 이미지 데이터 전송
        ↓
3. Python에서 이미지 Decode 및 얼굴 영역 추출
        ↓
4. FER 모델을 통한 감정 인식
        ↓
5. 감정 결과 Firebase 저장
        ↓
6. Unity에서 감정 데이터 수신
        ↓
7. 3D 아바타 표정 출력
```

서로 다른 실행 환경에서 동작하는 여러 모듈을 하나의 데이터 흐름으로 연결해  
감정 인식 결과가 모바일 서비스와 3D 아바타에 실시간으로 반영되도록 구현했습니다.

## 📚 What I Learned

이 프로젝트를 통해 AI 모델의 추론 결과를 단순히 출력하는 데서 끝내지 않고,  
**감정 인식 → 결과 안정화 → 공감 모델링 → 3D 표현 → 사용자 서비스**로 연결하는 전체 시스템을 설계하는 경험을 쌓았습니다.

특히 Android, Python, Firebase, Unity처럼 서로 다른 환경에서 동작하는 모듈을 연결하면서  
각 단계의 데이터 형식과 통신 흐름을 일관되게 설계하는 것이 중요하다는 점을 배웠습니다.

또한 실시간 AI 서비스에서는 모델 정확도뿐 아니라  
사용자에게 결과가 얼마나 자연스럽고 안정적으로 전달되는지도 중요하다는 점을 경험했습니다.
